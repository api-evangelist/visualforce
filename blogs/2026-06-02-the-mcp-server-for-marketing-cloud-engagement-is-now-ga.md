Salesforce has released a generally available MCP (Model Context Protocol) server for Marketing Cloud Engagement that enables AI agents like Claude to manage marketing tasks through a standardized interface. The server allows users to perform complex operations from creating data extensions to launching campaigns using plain language without writing code, while supporting flexible permissions and safety considerations for destructive operations.
