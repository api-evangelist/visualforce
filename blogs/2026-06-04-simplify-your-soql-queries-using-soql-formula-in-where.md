Salesforce is introducing FORMULA() in SOQL WHERE clauses, a pilot feature enabling developers to filter rows using computed formula expressions directly in queries rather than creating formula fields or post-processing in code. This capability is particularly valuable for ISVs and reduces schema complexity while improving performance through query-level filtering.
